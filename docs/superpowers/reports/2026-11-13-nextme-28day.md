## 만드는 법

- seed 1020
- 늦은 출근: 주 1일(수)
- 여행: D19~21(금~일). 원본은 2026-06-29~07-01이다.
- 화·목 운동
- 취미 2: 6일
- 취미 1: 레고(YouTube)

라벨 규칙은 `config/nextme_label_rules.l3.json`이다. 여행 날짜는 6/29~7/1이고, gym 규칙이 들어 있다.

```bash
npm run ingest -- nextme --days <114개 날짜> --clip-level L3 --source-dir data/raw/nextme-hf --overrides data/raw/bank/nextme800.overrides.json --out data/raw/bank/nextme800.l3.draft.jsonl --overwrite
npm run ingest -- bank --input data/raw/bank/nextme800.l3.draft.jsonl --dataset nextme800
npm run ingest -- egoexo --root data/raw/egoexo
npm run ingest -- bank --input data/raw/bank/youtube.lego.jsonl --dataset youtube
npm run compose-blocks -- --world config/worlds/nextme-p00.json --fit-roles hobby
```

- `data/raw/bank/nextme800.overrides.json`은 커밋하지 않는 데이터다. 다음 overrides가 들어 있다.
  - 수동 검토로 찾은 집 7구간
  - 연구실 아침 12구간
  - 같은 장소 사이 추정 55구간
- `youtube.lego.jsonl`은 "Pure Build LEGO Haunted House 10273"(MALryOlc3TU)의 세 파트다.
- 결과는 `data/exports/nextme-p00-<id>-r0.manifest.json`이고, block 모드 검사를 통과한다.
