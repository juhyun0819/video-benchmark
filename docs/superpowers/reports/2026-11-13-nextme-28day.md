- 여행: D19~21(금~일). 원본은 2026-06-29~07-01이다.
- 화·목 운동
- 취미 2: 6일
- 취미 1: 레고(YouTube)

라벨 규칙은 `config/nextme_label_rules.l3.json`이다. 여행 날짜는 6/29~7/1이고, gym 규칙이 들어 있다.

```bash
npm run ingest -- nextme --days <114개 날짜> --clip-level L3 --source-dir data/raw/nextme-hf --overrides data/raw/bank/nextme800.overrides.json --out data/raw/bank/nextme800.l3.draft.jsonl --overwrite
npm run ingest -- bank --input data/raw/bank/nextme800.l3.draft.jsonl --dataset nextme800
npm run ingest -- bank --input data/raw/bank/youtube.lego.jsonl --dataset youtube
python3 -I scripts/convert_ego4d_narrations.py --metadata data/raw/ego4d/ego4d.json --narrations data/raw/ego4d/v2/annotations/narration.json --out data/raw/ego4d/narration_selected.json
npm run ingest -- ego4d --metadata data/raw/ego4d/ego4d.json --narrations data/raw/ego4d/narration_selected.json
npm run compose-blocks -- --world config/worlds/nextme-p00.json --fit-roles hobby --pins config/worlds/nextme-p00.pins.json --meal-fill-node eat_out_ext
python3 -I scripts/render_proxy.py --manifest data/exports/<id>-r0.manifest.json --timeline data/timelines/<id>.json --out data/renders/nextme-p00/realtime_1fps
python3 -I scripts/render_proxy.py --manifest data/exports/<id>-r0.manifest.json --timeline data/timelines/<id>.json --out data/renders/nextme-p00/quicklook_60x --speed 60 --fps 30
```

- `data/raw/bank/nextme800.overrides.json`은 커밋하지 않는 데이터다. 다음 overrides가 들어 있다.
  - 수동 검토로 찾은 집 7구간
  - 연구실 아침 12구간
  - 같은 장소 사이 추정 55구간
- `youtube.lego.jsonl`은 "Pure Build LEGO Haunted House 10273"(MALryOlc3TU)의 세 파트다.
- 결과는 `data/exports/nextme-p00-<id>-r0.manifest.json`이고, block 모드 검사를 통과한다.

## 하루 구성 (실제 영상 기준 요약)

- **D1 월**: 아침에 아파트에서 짐을 챙기고 쓰레기를 버린 뒤 나선다. 오전 내내 도서관 열람실에서 확률론(램지 수) 공부와 연구를 하고, 구내식당에서 산 닭고기 덮밥을 야외 테라스에서 먹는다. 오후에는 그래프 이론 강의를 듣고 Flow Matching 강의 영상과 Claude로 유도 과정을 공부하며 노트에 식을 정리한 뒤, 캠퍼스를 가로질러 택배 보관소에서 소포를 찾는다. 저녁에는 일행과 식당에 가서 메뉴를 고르고 함께 식사한다. 그 뒤 집에 와서 책상을 정리하고, AI와 함께 행동 예측 평가 프로토콜과 평가 프롬프트를 만든다.

- **D2 화**: 아침에 빨래를 돌리고 물을 마신 뒤, 출근길에 루이싱 커피를 받아 연구실에 자리 잡는다. 오전에는 멀티모달 파인튜닝 체크포인트 점수와 스케일링 곡선 시각화를 정리하고, 점심은 집에 들러 만두·계란·채소를 볶아 영상을 보며 먹는다. 오후에는 동료와 데이터 삭제 사고를 이야기하고 행동 병합 프롬프트를 다듬은 뒤 DDPM 논문을 손으로 정리하고, 퇴근 후 헬스장에서 벤치프레스와 케이블 운동을 한다. 저녁은 일행과 함께 먹고, 밤에는 집에서 프록시 설정을 고치고 Gemini로 world-model 시뮬레이션 자료를 찾는다.

- **D3 수**: 늦은 출근일. 오전에 집에서 짐과 프로젝트 노트를 정리한 뒤, 도서관에서 이분 그래프 숙제와 CS285 메타러닝을 공부한다. 점심은 일행과 식당에서 간식과 주스를 곁들여 먹고, 오후에는 도서관에서 DMER 에이전트 연구와 확률·그래프 문제를 풀다가 강의실로 옮겨 기말시험 안내를 듣는다. 저녁에는 식당에서 휴대폰으로 메뉴를 스캔해 주문하고 일행과 식사한 뒤, 밤에는 방에서 확률 숙제(로바스 국소 보조정리)를 마무리하고 한국 드라마를 보며 쉰다.

- **D4 목**: 아침에 잃어버린 열쇠를 찾느라 집 안을 뒤진 뒤 출근한다. 오전에는 VLM 일반화 연구 노트와 VRS 영상 마스킹 스크립트를 정리하고, 구내식당에서 동료들과 점심을 먹는다. 오후에는 개인정보 파이프라인 테스트 결과를 공유하고 L3 평가 채점을 돌린 뒤, 헬스장에서 풀업과 덤벨 숄더프레스를 한다. 동료들과 구내식당에서 저녁을 먹고 귀가해 방에서 기타를 친 뒤, 전기 훠궈 냄비에 육수를 끓이고 고기를 썰어 훠궈를 준비한다.

- **D5 금**: 아침 준비를 마치고 출근해, 오전에는 심리학·감정 연구 노트와 Lucia RAG 평가 지표를 정리하고 박사 지도교수 후보를 찾아본다. 구내식당에서 파 국수와 반찬으로 점심을 먹고, 오후에는 줌 세미나(LLM과 심리학, 마음 이론)를 들으며 CS285 과제와 행동 모델링 노트를 쓴 뒤, 타오바오에서 Claude Pro를 사서 LLM-judge 평가를 돌린다. 일찍 퇴근한 날이라 일행과 식탁에서 저녁을 먹고 방에서 기타를 친다. 밤에는 침대 책상에서 평가 문서와 업무 연락을 정리하고 빨래를 넌다.

- **D6 토**: 쉬는 토요일. 아침에 침실에서 수영 가방과 노트북 충전기를 챙기고, 오전 내내 레고 '헌티드 하우스' 1부(약 2시간 13분)를 조립한다. 점심은 캠퍼스 식당 뷔페에서 샐러드부터 먹고, 오후에 아파트 쓰레기를 버린다. 저녁은 일행과 식당에서 식사하고, 집에 들어와 위챗과 마이크 리뷰를 보고 egocentric 비디오-언어 모델 코드를 살펴본다.

- **D7 일**: 쉬는 일요일. 오전에 집에서 행동 예측 데이터셋을 찾고 ARIN7102 과제를 한다. 점심은 일행과 식당에서 먹고 디저트까지 든다. 오후에는 단기 임대 매물을 알아보고, 저녁에 계란 토르티야 전을 부쳐 룸메이트와 나눠 먹는다. 밤에는 룸메이트와 이사 계획을 이야기하며 춘권피를 함께 만들고, 책상에서 기술 뉴스와 메시지를 본다.

- **D8 월**: 아침에 집에서 장기 행동 예측 모델(AntGPT, DeepSeek) 평가를 하다가 출근한다. 오전에는 Jake·Alice 데이터셋 처리 로그와 MCP 터널 오류를 손보고, 캠퍼스 서점을 둘러본 뒤 빈 강의실과 라운지에서 VPS와 Claude Pro를 구매한다. 구내식당에서 동료들과 점심을 먹고, 오후에는 Jake Day1 데이터 처리와 음성 익명화, VideoChat3 논문, HippoRAG 논의를 한 뒤 박사 지도교수 후보를 정리하고 Bilibili 영상을 본다. 저녁엔 광장에서 친구들과 수박을 나눠 먹고, 장 본 것을 들고 귀가해 침실에서 친구와 닭 연골 튀김을 나눠 먹는다.

- **D9 화**: 아침에 택배를 뜯어 보고 타오바오와 메일을 확인한 뒤 출근한다. 오전에는 Lucia 영상 재생과 자막 주석 파일을 정리하고 아트리움 라운지에서 잠깐 쉰 뒤, 도서관 책상에서 머신러닝 과제(퍼셉트론, 결정 트리)를 푼다. 점심을 동료들과 먹고, 오후에는 SFT 일반화 실험과 Lucia 테스트 데이터를 점검하고 신념 구조에 관한 연구 발표를 듣는다. 퇴근 후 헬스장에서 하체 운동을 하고 구내식당에서 14.5위안짜리 저녁을 먹은 뒤, 집에서 기타를 치고 룸메이트들과 이야기를 나눈다.

- **D10 수**: 늦은 출근일. 아침에 맥북과 택배 물건을 가방에 챙겨 나서고, 오전에는 CS285 숙제와 LLM-judge 벤치마크 설계를 공부하며 동행의 BOCHK 앱 등록을 돕는다. 점심은 집에서 계란·다진 고기 볶음밥을 만든다. 오후에는 캠퍼스 라운지와 강의실에서 감정 계산 모델과 디지털 트윈을 조사하고 동행의 jsPsych 실험 배포를 도운 뒤, SFT 데이터 선택(LESS, GRAPE) 논문을 정리한다. 저녁은 식당에서 고양이와 놀며 국수와 밥을 먹는다.

- **D11 목**: 아침에 집에서 행동 예측·감정 모델링 논문을 찾고 출근한다. 오전에는 하드디스크 상태와 GPU 사양을 점검하고, 구내식당에서 점심을 먹는다. 오후에는 시선(eye-gaze) 보정 데이터와 데이터 마스킹 파이프라인을 점검하고 박사 지원 연구계획서를 다듬은 뒤, 헬스장에서 친구와 풀업·벤치프레스를 하며 감정 모델링을 이야기한다. 식당에서 국수로 저녁을 먹고 귀가해 책상 서랍의 물건을 살펴본다.

- **D12 금**: 아침에 침대에서 AI 기사와 SNS를 보다가 출근한다. 오전에는 Codex·Claude Code 메모리 설정과 시선 추적 데이터 스크립트를 손보고, LLM-judge 후보 모델을 골라 평가 프롬프트를 제출한다. 구내식당에서 동료들과 AI 이야기를 하며 점심을 먹고, 오후에는 출입카드 시뮬레이션 테스트와 교수진 발표(LLM, 로봇, 드론)를 들은 뒤 Lucia 영상 행동 분석 노트를 쓴다. 저녁은 구내식당에서 석사 지원 계획을 이야기하며 먹고, 밤에는 집에서 방을 치우고 짱구를 본 뒤 alphaXiv 논문과 대사 스케일링 법칙 전자책을 읽는다.

- **D13 토**: 쉬는 토요일. 아침에 Claude Code 로그를 확인하고 강화학습 내재 동기를 공부한 뒤, 오전에 레고 2부(약 1시간 46분)를 조립한다. 늦은 점심은 친구들과 식당에서 도넛과 주스를 곁들여 먹는다. 오후에는 집에서 평가 진행 상황을 보다가 잃어버린 학생증 때문에 룸메이트와 다투고 달랜 뒤, 부동산 중개인에게 임대 조건을 전한다. 저녁은 식당에서 일행과 디저트까지 먹고 트램 쪽으로 걸어 나오며, 밤에는 부동산에 단기 임대를 문의하고 집 보러 갈 일정을 잡는다.

- **D14 일**: 쉬는 일요일. 아침에 휴대폰 네트워크를 고치고 데이터 요금제를 산 뒤, 오전 내내 집에서 습관 트리거 연구와 행동 평가 채점 규칙을 정리하고 상하이 비행 일정을 잡는다. 점심은 일행과 식당에서 먹고, 오후에는 여자친구에게 마사지를 해 주며 루브릭 점수를 매기고 방을 정리한다. 저녁은 룸메이트와 식탁에서 먹고, 밤에는 집 이야기를 하며 장을 봐 와 정리하고 설거지를 한 뒤 생필품을 온라인으로 주문한다.

- **D15 월**: 아침에 노트북을 챙기고 조용한 스터디 공간을 찾아본 뒤 출근한다. 오전에는 게스트 Wi-Fi 프록시 오류를 고치고 Anthropic 감정 프로브 프로젝트를 조사한 뒤, Qwen VLM 파인튜닝 환경을 꾸려 Codex로 학습 작업을 제출한다. 점심은 식당에서 일행과 타코를 먹고, 오후에는 모델 다운로드를 지켜보며 감정 벡터 논문을 읽은 뒤 일찍 퇴근한다. 저녁은 쇼핑몰의 스시 익스프레스에서 초밥을 먹고 빵집에 들른 뒤, 방에서 기타를 친다.

- **D16 화**: 아침에 집에서 하루를 준비하고 출근한다. 오전에는 MAGIC-Video 평가 지표와 Jake 데이터셋 처리, 자막 재작성, OCR 개인정보 마스킹을 하고 Qwen3.5 벤치마크 점수를 정리한 뒤, 구내식당에서 점심을 먹는다. 오후에는 야외 피크닉 테이블과 도서관에서 Flow 모델과 증명 문제를 공부하고, 저녁에 헬스장에서 벤치프레스를 하며 친구의 케이블 운동을 돕는다. 구내식당에서 늦은 저녁을 먹고, 밤에는 짧은 드라마를 보다가 과학 도식 템플릿을 만든다.

- **D17 수**: 늦은 출근일. 아침 9시부터 집에서 게임 '디스코 엘리시움'을 30분쯤 하다가 아파트를 나선다. 치대 건물 도서관에서 ARIN7013 시험 공부(피카르 반복법, 오일러 오차)를 하고, 카페 드 코랄에서 늦은 점심(로스트 고기 덮밥)을 먹은 뒤 치대 도서관으로 돌아가 CS285와 diffusion policy를 저녁까지 공부한다. 구내식당에서 매운 닭고기로 저녁을 먹고 귀가해, 터미널 로그를 확인하고 기타 연습 영상을 보며 기타와 노래를 연습한다.

- **D18 목**: 아침에 집에서 계층적 행동 예측 예시를 정리하고 Claude Code로 SVG 도식을 만든 뒤 출근한다. 오전에는 USB 이더넷 연결을 고치고 파인튜닝 손실 곡선과 2단계 학습을 준비하며, 자전거 거치대 옆에서 햇볕을 쬐며 쉰다. 점심은 식당에서 일행과 서빙된 음식을 먹고, 오후 내내 행동 예측 문헌과 비디오 사전학습 논문을 보며 학습률 스윕을 돌린다. 저녁에 동료들과 헬스장에서 풀업과 벤치프레스를 하고 연구실에 들렀다가, 식당에서 휴대폰으로 메뉴를 스캔해 주문하고 스무디를 곁들여 늦은 저녁을 먹는다. 밤 10시쯤 귀가해 행동 예측 시나리오 채점 코멘트를 단다.

- **D19 금**: 여행 첫날(금). 호텔 방에서 준비하고 로비로 내려가 뷔페 아침을 먹는다. 관광 셔틀을 타고 보행자 광장을 지나 해변을 둘러보고, 오후에는 전동 카트를 몰고 목적지로 간다(점심 장면은 없다). 저녁은 밍스산예 식당에서 동행과 먹고, 밤에는 리조트 캐빈을 살펴보고 일행과 리조트를 돌며 사진을 찍은 뒤 스쿠터를 빌린다.

- **D20 토**: 여행 둘째 날(토). 캐빈에서 씻고 노트북 일을 본 뒤 식당에서 동행과 뷔페 아침을 먹는다. 짐을 차에 싣고 시골길을 달려 더톈 폭포에 가고, 오후에는 전동 스쿠터로 룽궁셴징 입구와 강변 산길을 달린다(점심 장면은 없다). 저녁은 닭고기와 찹쌀밥을 먹으며 일행과 어울리고, 밤에는 강가 전망대에 들렀다가 라오무멘 리조트를 스쿠터로 둘러본다.

- **D21 일**: 여행 마지막 날(일). 호텔에서 나와 라운지의 새를 구경하고 뷔페에서 죽과 옥수수, 고구마로 아침을 먹는다. 블루홀 공원에서 동굴 카페와 대나무 숲길, 구이춘강 급류를 보고 공원 식당에서 점심을 먹은 뒤, 차를 몰고 산길과 고속도로를 달려 돌아온다. 저녁은 야시장에서 구운 굴과 찐빵, 국수를 먹다가 부동산 중개인과 실랑이를 하고, 밤에는 호텔에 체크인한 뒤 동행과 상가를 걷고 돌아온다.

- **D22 월**: 아침에 룸메이트들과 어울린 뒤 출근한다. 오전에는 페이슈에 일기와 기타 연습 기록을 쓰고 선호도 평가와 AutoDL 설정을 하며, 구내식당에서 동료들과 점심을 먹는다. 오후에는 잠깐 바깥 산책을 하고 여자친구의 VPN 문제를 원격으로 도운 뒤, IQL 강화학습 코드를 구현하고 MAC Lab 줌 회의에 들어간다. 저녁은 구내식당에서 완탕과 만두를 먹고, 밤에는 집에서 옷과 기기를 챙긴다.

- **D23 화**: 아침에 부엌에서 계란·소시지·토마토 샌드위치를 만들고 출근한다. 오전에는 LongNAP 논문과 내재 보상 논문을 읽고, 구내식당에서 AI 모델 이야기를 하며 점심을 먹는다. 오후에는 행동 예측 베이스라인과 Day 4 타임라인을 분석하다가 도서관으로 옮겨 커널 방법과 수치해석 과제를 공부하고, 퇴근 후 헬스장에 다녀와 연구실에 들른다. 저녁은 식당에서 타코와 레모네이드를 먹고 아이스크림까지 든 뒤, 방에서 기타 줄을 조율하고 연주한다. 밤에는 룸메이트들과 1년 임대 계약을 상의하고, Claude Code로 모델 벤치마크를 본 뒤 짧은 영상을 본다.

- **D24 수**: 늦은 출근일. 아침에 방에서 책상 물건을 정리하고 화장실 배수구를 손본 뒤 나선다. 도서관 열람실에서 ARIN7013 시험 자료와 오일러 방법, 로렌츠 시스템 시뮬레이션을 공부하고, 지하 주차장을 지나 구내식당에서 점심을 먹는다. 오후에는 Neural ODE 과제와 Qwen3 임베딩 벤치마크를 진행하고, 저녁에 집에서 채소·고기 볶음밥을 만들어 여자친구와 위챗을 하며 먹는다. 밤에는 SNS를 보고 부엌을 치우고 쓰레기를 버린다.

- **D25 목**: 아침에 쇼핑 앱에서 머리띠를 고른 뒤 출근한다. 오전에는 데이터셋 오류 우선순위와 복구 계획을 세우고 얼굴 검출 지표를 살펴본 뒤 택배를 10층으로 옮기고, 구내식당에서 점심을 산다. 오후에는 음성 익명화 파이프라인과 데이터 정제 작업을 하고 강의를 들으며 AI 논문을 공부한 뒤, 일찍 퇴근해 친구와 헬스장에서 케이블과 보조 벤치프레스를 한다. 저녁은 쇼핑몰 빵집의 치즈 토스트로 간단히 먹고 방에서 기타를 친 뒤, 밤에는 Gemini로 EgoLife 데이터셋을 찾아 Colab에서 내려받는다.

- **D26 금**: 아침에 부엌에서 손발톱을 깎고 출근한다. 오전에는 Wi-Fi와 캡티브 포털 인증 문제를 고치며 컨텍스트 스케일링 평가 보고서를 정리하고, 구내식당에서 동료들과 점심을 먹는다. 오후에는 사건 분할 이론을 공부하고 Project Aria 시선 데이터 작업과 LLM-judge 배치를 평가한 뒤 연구 노트를 정리한다. 저녁은 구내식당에서 친구들과 생선튀김을 먹고, 밤에는 집에서 POV 뷰어 문서 작업과 직소 퍼즐을 한다.

- **D27 토**: 쉬는 토요일. 아침에 룸메이트들, 새끼 고양이와 어울리고, 오전에 레고 3부(약 2시간 51분)를 조립해 헌티드 하우스를 완성한다. 점심은 바허리 식당에서 동행과 훠궈를 먹고, 오후에는 집에서 인테리어 이야기를 나눈다. 저녁은 일행과 식당에서 먹고, 밤에는 휴대폰으로 급하게 리스크 분석 조 회의에 들어간다.

- **D28 일**: 쉬는 일요일. 아침에 AutoDL 클라우드를 손보고 LLM 감정 개념 연구를 정리한 뒤 냉장고 성에를 긁어낸다. 점심은 일행과 식당에서 라자냐를 먹고 카드로 계산하고, 오후에는 삼겹살을 산다. 저녁은 식당에서 일행과 먹고 마신 뒤, 집에 와서 설거지를 하고 방에서 'Attention Is All You Need' 논문을 다시 읽는다.
